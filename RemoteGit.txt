1. git clone "repo-url"
➡️ Copies a remote repository to your local system

2. git remote
➡️ Shows connected remote repositories

3. git remote -v
➡️ Shows remote URLs (fetch + push)

4. git remote add origin "url"
➡️ Connects local repo to a remote repo

5. git remote remove origin
➡️ Removes remote connection

6. git push origin branch-name
➡️ Uploads your code to GitHub

7. git push -u origin branch-name
➡️ Push + sets upstream branch

8. git push
➡️ Pushes code (after upstream is set)

9. git pull
➡️ Fetch + merge latest code from remote

10. git fetch
➡️ Downloads latest code but does NOT merge

11. git pull origin branch-name
➡️ Pulls specific branch from remote

12. git push origin --delete branch-name
➡️ Deletes branch from remote

13. git branch -r
➡️ Shows remote branches

14. git branch -a
➡️ Shows all branches (local + remote)

15. git checkout -b branch origin/branch

➡️ Creates local branch from remote branch

16. git push origin HEAD

➡️ Push current branch

17. git remote rename old new

➡️ Renames remote
